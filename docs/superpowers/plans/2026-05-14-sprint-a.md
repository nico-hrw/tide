- [ ] **Step 2: Guard the notes/events state update**

Find this set call (around line 877):
```typescript
set(s => ({
    notes: visibleNotes,
    events: visibleEvents,
    metadataCache: newMetaCache,
```

Replace with:
```typescript
set(s => ({
    // Only replace existing data if we actually received items from the server.
    // An empty result most likely means a network hiccup, not that the user deleted everything.
    notes: visibleNotes.length > 0 || s.notes.length === 0 ? visibleNotes : s.notes,
    events: visibleEvents.length > 0 || s.events.length === 0 ? visibleEvents : s.events,
    metadataCache: newMetaCache,
}));
```

Replace with:
```typescript
set(s => {
    // Don't wipe existing tasks if the server returned nothing
    if (loadedTasks.length === 0 && s.tasks.length > 0) return {};
    const localMap = new Map(s.tasks.map(t => [t.id, t]));
    const merged = loadedTasks.map(bt => {
        const local = localMap.get(bt.id);
        if (local && local.scheduledDate && !bt.scheduledDate) return { ...bt, scheduledDate: local.scheduledDate };
        if (local && local.isCompleted !== bt.isCompleted) return local;
        return bt;
    });
    return { tasks: merged };
```
