## Task 3: Time-based event spacing

**Files:** `web/src/components/Layout/MobileLayout.tsx`

Read the current file first.

- [ ] **Step 1: Replace gap-6 with time-based marginTop on each event**

Find the timeline container div inside `timedEvents.length === 0 ? null : (`:
```tsx
<div className="relative flex flex-col gap-6">
```

Change to:
```tsx
<div className="relative flex flex-col">
```

Inside `timedEvents.map((event, idx) => {`, compute `marginTop` from the previous event's end time:

Add this computation at the very top of the map callback (after existing `const startDate`, `const endDate`, etc.):

```tsx
// Time-proportional spacing
const prevEvent = idx > 0 ? timedEvents[idx - 1] : null;
const gapMs = prevEvent
  ? new Date(event.start).getTime() -
    new Date(prevEvent.end || prevEvent.start).getTime()
  : 0;
const gapMinutes = Math.max(0, gapMs / 60_000);
const eventMarginTop = idx === 0 ? 0 : Math.round(Math.max(8, Math.min(56, 8 + (gapMinutes / 60) * 64)));
```

Then add `style={{ marginTop: eventMarginTop + 'px' }}` to the outermost div of each event row:

```tsx
<div
  key={`${event.id}-${idx}`}
  onClick={() => setExpandedEventId(isExpanded ? null : event.id)}
  className="flex gap-4 cursor-pointer relative z-10"
  style={{ marginTop: eventMarginTop + 'px' }}
>
```
